# 💰 PocketSmart AI

PocketSmart AI is an AI-powered personal budgeting and recommendation
web application.

## Features

- Monthly income input
- Monthly expense tracking
- AI-powered budget analysis
- Spending recommendations
- Saving suggestions
- Suggested monthly budget
- FastAPI backend
- Gemini AI integration
- Jinja2 web interface

## Technology Stack

- Python
- FastAPI
- Gemini API
- Jinja2
- HTTPX
- HTML
- CSS
